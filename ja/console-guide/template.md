<h1>テンプレート</h1>

**Notification > Notification Hub > コンソール使用ガイド > テンプレート**


<span id="template"></span>

## テンプレート

よく使用するメッセージや一定の形式が必要なメッセージをテンプレートとして保存しておき、送信時に保存したテンプレートを設定してメッセージを送信できます。たとえば、カスタマーサポート、お知らせ、通知、またはマーケティングメッセージなど、よく使用するメッセージの形式をテンプレートとして作成しておくと、毎回同じ内容を作成する必要なく、一部の情報のみを修正して送信できます。

<a id="category"></a>

### カテゴリ
* まずルートカテゴリを選択し、**[+ カテゴリ追加]** をクリックしてカテゴリを作成します。
* カテゴリは選択されたカテゴリの配下に作成されます。

<a id="template"></a>

### テンプレート
1. テンプレートが属するカテゴリを選択し、**[+ テンプレート登録]** をクリックします。テンプレート作成ページに移動し、選択したメッセージチャンネルの追加設定が表示されます。
2. タイトルと内容、および各メッセージチャンネルが要求する設定を完了し、**[登録]** をクリックします。

<a id="alimtalk-template"></a>

#### お知らせトークテンプレート

お知らせトークテンプレートは、登録リクエスト後にカカオの検収承認を受けてから使用できます。

* 登録可能なメッセージタイプには、チャンネル追加型、基本型、付加情報型、複合型があります。
* 登録可能な強調タイプには、強調表記型、イメージ型、アイテムリスト型があります。
* 希望のタイプを選択してテンプレートを作成してください。

* カカオお知らせトークガイド
    * [[お知らせトーク制作ガイド]](https://kakaobusiness.gitbook.io/main/ad/bizmessage/notice-friend/content-guide)、[[お知らせトーク審査ガイド]](https://kakaobusiness.gitbook.io/main/ad/bizmessage/notice-friend/audit)、[[お知らせトークホワイトリスト]](https://kakaobusiness.gitbook.io/main/ad/bizmessage/notice-friend/audit/white-list)、[[お知らせトークブラックリスト]](https://kakaobusiness.gitbook.io/main/ad/bizmessage/notice-friend/audit/black-list)
* 発信プロフィール/グループ
    * テンプレートを登録する発信プロフィールまたは発信プロフィールグループを選択します。グループに登録した場合、グループに含まれるすべての発信プロフィールがそのテンプレートを使用できます。
    * 発信プロフィール/グループに同一のテンプレートコードが存在する場合、発信プロフィールに登録されたテンプレートが優先して送信されます。
    * 発信プロフィールグループの場合、メッセージタイプのうち「チャンネル追加型」「複合型」ではテンプレートを登録できません。
* テンプレートコード/テンプレート名
    * 1つの発信プロフィール/グループに同一のテンプレートコードとテンプレート名を重複して登録することはできません。

* テンプレート内容
    * お知らせトークは、日本語・英語の区別なく、変数および URL、スペース、ボタン名をすべて含めて 1,000 文字まで作成できます。変数を入力して登録する場合は、置換される内容も考慮してテンプレートを作成してください。<br/> 文字数の詳細ガイドは [お知らせトークテンプレート注意事項](https://docs.nhncloud.com/ko/Notification/KakaoTalk%20Bizmessage/ko/alimtalk-overview/#_3) で確認してください。
    * 変数は `#{変数}` 形式で記述します。（例: `#{홍길동}` 様の宅配便が本日 `（#{09:50}）` にお届けされる予定です。）
    * ボタン登録時、ボタン名には変数を入力できませんが、ボタン URL には変数を入力できます。（例: `http://kakao.com/#{変数}`）
    * ボタン URL 登録時、url_mobile・url_pc リンクには `http://` または `https://` が含まれている必要があり、scheme_ios・scheme_android リンクはスキーム形式に合わせて登録する必要があります。これを満たさない場合、テンプレートを登録できません。
* セキュリティテンプレートの設定
    * テンプレートをセキュリティ設定にすると、モバイル以外のデバイスではメッセージ内容が表示されません。（「モバイルでご確認ください」という文言が表示されます）
    * 一般メッセージの場合、検収時に設定値が変更される場合があります。OTP、認証番号、パスワード、信用情報/等級変更案内テンプレートは必ずセキュリティを有効にしてください。

#### お知らせトークテンプレートボタン
* テンプレートあたり最大 5 個のボタンを登録できます。
* クイック接続
    * 配送照会およびプラグインタイプは使用できません。それ以外のタイプはボタンと同様に使用できます。
    * テンプレートあたり最大 10 個まで使用でき、クイック接続を使用する場合はボタンの数が 2 個に制限されます。

| ボタン種類 | 説明 |
| --- | --- |
| 配送照会 | - 配送業者の配送照会ページに移動します。<br/> - 配送照会ボタンをサポートする配送業者と、配送業者別の送り状番号パターンを確認します。[[お知らせトーク配送照会送り状番号パターン案内]](https://www.nhncloud.com/kr/support/notice/detail/1455)|
| Webリンク | - モバイルまたは PC の Web ページに移動します。<br/> - URL リンクを変数として設定できます。 |
| アプリリンク | - カスタムスキームでアプリを起動します。<br/> - Android と iOS で起動するカスタムスキームをそれぞれ設定する必要があります。 |
| ボットキーワード | - ボタン名がオペレーターに送信されます。<br/> - 相談トークをサポートしないチャンネルがこのボタンを追加すると、お知らせトークの送信ができません。 |
| メッセージ転達 | - ボタン名とメッセージ本文がオペレーターに送信されます。<br/> - 相談トークをサポートしないチャンネルがこのボタンを追加すると、お知らせトークの送信ができません。 |
| 相談トーク転換 | - 相談トークに接続されます。<br/> - 相談トークをサポートしないチャンネルがこのボタンを追加すると、お知らせトークの送信ができません。 |
| ボット転換 | - チャットボットが呼び出されます。<br/> - 相談トークをサポートしないチャンネルがこのボタンを追加すると、お知らせトークの送信ができません。 |
| チャンネル追加 | - お知らせトークを送信したチャンネルを追加します。表示位置は最初のボタンとしてのみ使用できます。<br/> - すでにチャンネルが追加されている場合、受信者には表示されません。 |
| イメージセキュリティ送信プラグイン | - チャット画面内で機密情報を含む画像を暗号化して送信します。<br/> - BizPluginの作成が必要です。[[BizPluginガイド]](https://business.kakao.com/info/talkbizplugin/) |
| 個人情報利用プラグイン | - チャット画面内で会員登録なしにサービス提供に必要な個人情報の収集同意を取得します。<br/> - BizPluginの作成が必要です。[[BizPluginガイド]](https://business.kakao.com/info/talkbizplugin/) |
| ワンクリック決済プラグイン | - チャット画面内で画面遷移なしにユーザーが商品を決済できます。<br/> - 決済プラグインはプラットフォームからの直接登録をサポートしていないため、[カカオカスタマーセンター](https://cs.kakao.com/helps?service=127&category=572&locale=ko) にお問い合わせください。 |
| ビジネスフォーム | - ビジネスフォームを作成して現在のチャンネルと連携した場合、ボタンクリック時に設定したビジネスフォームが呼び出されます。<br/> - ビジネスフォームの作成が必要です。[[ビジネスフォームガイド]](https://business.kakao.com/info/talkbizform/) |

<a id="template-inspection"></a>

#### テンプレート検収
お知らせトークテンプレートの検収および審査はカカオが直接実施し、検収リクエスト後、営業日基準で 2 日以内に順次処理されます。

* テンプレートへのお問い合わせ登録
    * 検収リクエスト前にカカオの検収担当者に伝えたい意見がある場合は、お問い合わせ登録欄に内容を入力します。リクエスト済み/承認済み状態のテンプレートはお問い合わせできません。（**検収中/反映**状態のテンプレートのみお問い合わせを登録できます。）
    * 登録したお問い合わせは検収結果に追加され、カカオの検収担当者が確認します。
    * 検収結果にテンプレートの用途に関するお問い合わせと差し戻し理由の内容が追加されます。
    * テンプレートが差し戻された場合、**[お問い合わせ登録]** および **[修正]** をクリックして再検収を申請できます。

<a id="template-status"></a>

#### テンプレートステータス
* テンプレート登録時、**リクエスト済み → 検収中 → 承認済み/差し戻し** の順にステータスが更新されます。
* テンプレート登録後、1 年間同一のステータスが維持される、または追加の送信がない場合、**休眠**状態に移行します。関連ガイドは [お知らせトークテンプレート注意事項](https://docs.nhncloud.com/ko/Notification/KakaoTalk%20Bizmessage/ko/alimtalk-overview/#_3) で確認してください。

<a id="modify-templates"></a>

#### テンプレートの修正
* **承認済み/差し戻し**状態のテンプレートのみ修正できます。
* 承認済みのテンプレートを修正し、検収が完了すると、既存のテンプレート内容が修正した内容に置き換えられます。
* 発信プロフィール/グループおよびテンプレートコードは修正できません。
* 修正したテンプレートは **検収中** 状態から再度検収が進行されます。

<a id="delete-templates"></a>

#### テンプレートの削除
* リクエスト済み/差し戻し状態のテンプレートのみ削除できます。
* 差し戻されたテンプレートは **[削除]** 後に再登録できます。
* 削除されたテンプレートコードは再利用できます。

#### ブランドメッセージテンプレート
ブランドメッセージテンプレートはお知らせトークテンプレートとは異なり、検収プロセスがなく、作成・修正・削除を自由に行えます。

* 発信プロフィールを選択してテンプレートを登録します。
* テンプレートコードはユーザーが直接登録する方式ではなく、カカオがランダムな識別子を付与します。
* メッセージタイプを選択して内容を作成します。
    * サポートするメッセージタイプ: テキスト、イメージ、ワイドイメージ、ワイドアイテムリスト、カルーセルフィード、プレミアム動画、コマース、カルーセルコマース
* ボタンを登録できます。
    * サポートするボタンタイプ: Web リンク、アプリリンク、ボットキーワード、メッセージ転達、相談トーク転換、ボット転換、ビジネスフォーム、チャンネル追加
* クーポンを登録できます。
* イメージを添付するには、あらかじめイメージを登録する必要があります。

#### 共用お知らせトークテンプレート
共用お知らせトークテンプレートは、カカオが直接制作・検収して公開したテンプレートです。すべての事業者が共通して使用でき、特定の発信プロフィールに帰属しません。カカオの検収がすでに完了した状態で提供されるため、別途の検収リクエストなしにすぐ送信に使用できます。

* 自動登録
    * 発信プロフィールを登録すると、共用お知らせトークテンプレートが自動的に同期されてコンソールに表示されます。以降、カカオに新しい共用テンプレートが公開されると、定期的に自動同期されます。
    * 共用お知らせトークテンプレートは **カカオ** カテゴリ配下に自動的に分類されます。このカテゴリはシステムが作成・管理するため、ユーザーが直接修正または削除することはできません。
* 使用制約
    * 共用お知らせトークテンプレートはカカオが管理するため、コンソールから修正または削除することはできません。
    * 共用お知らせトークテンプレートを一般カテゴリに移動したり、一般テンプレートを **カカオ** カテゴリに移動したりすることはできません。
* 送信
    * 共用お知らせトークテンプレートは特定の発信プロフィールに帰属しないため、送信時に使用する発信プロフィールを直接選択する必要があります。
    * アクティブ状態の発信プロフィールが 1 つ以上登録されている必要があります。
    * 検収が完了した状態であるため、検収待ちなしにすぐ送信できます。
