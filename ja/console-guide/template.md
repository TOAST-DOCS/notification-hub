<h1>テンプレート</h1>

**Notification > Notification Hub > コンソール使用ガイド > テンプレート**


<span id="template"></span>

## テンプレート

よく使用するメッセージや一定の形式が必要なメッセージをテンプレートとして保存しておき、送信時に保存済みのテンプレートを設定してメッセージを送信できます。たとえば、カスタマーサポート、お知らせ、通知またはマーケティングメッセージなど、よく使用するメッセージの形式をテンプレートとして作成しておくと、毎回同じ内容を作成する必要なく、一部の情報を修正するだけで送信できます。

<a id="category"></a>

### カテゴリ
* まずルートカテゴリを選択し、**[+ カテゴリ追加]** をクリックしてカテゴリを作成します。
* カテゴリは選択されたカテゴリの配下に作成されます。

<a id="template"></a>

### テンプレート
1. テンプレートが属するカテゴリを選択し、**[+ テンプレート登録]** をクリックします。テンプレート作成ページに移動し、選択されたメッセージチャンネルの追加設定が表示されます。
2. タイトルと内容、および各メッセージチャンネルで必要な設定を完了し、**[登録]** をクリックします。

<a id="alimtalk-template"></a>

#### お知らせトークテンプレート

お知らせトークテンプレートは、登録リクエスト後にKakaoの審査承認を受けてから使用できます。

* 登録可能なメッセージタイプには、チャンネル追加型、基本型、付加情報型、複合型があります。
* 登録可能な強調タイプには、強調表記型、イメージ型、アイテムリスト型があります。
* 希望するタイプを選択してテンプレートを作成します。

* Kakaoお知らせトークガイド
    * [[お知らせトーク制作ガイド]](https://kakaobusiness.gitbook.io/main/ad/bizmessage/notice-friend/content-guide)、[[お知らせトーク審査ガイド]](https://kakaobusiness.gitbook.io/main/ad/bizmessage/notice-friend/audit)、[[お知らせトークホワイトリスト]](https://kakaobusiness.gitbook.io/main/ad/bizmessage/notice-friend/audit/white-list)、[[お知らせトークブラックリスト]](https://kakaobusiness.gitbook.io/main/ad/bizmessage/notice-friend/audit/black-list)
* 発信プロフィール/グループ
    * テンプレートを登録する発信プロフィールまたは発信プロフィールグループを選択します。グループに登録した場合、グループに含まれるすべての発信プロフィールがそのテンプレートを使用できます。
    * 発信プロフィール/グループに同一のテンプレートコードが存在する場合、発信プロフィールに登録されたテンプレートが優先して送信されます。
    * 発信プロフィールグループの場合、メッセージタイプのうち「チャンネル追加型」「複合型」ではテンプレートを登録できません。
* テンプレートコード/テンプレート名
    * 1つの発信プロフィール/グループに同一のテンプレートコードとテンプレート名を重複して登録することはできません。

* テンプレート内容
    * お知らせトークは、言語を問わず変数およびURL、スペース、ボタン名をすべて含めて1,000文字まで作成できます。変数を入力して登録する場合、置換後の内容も考慮してテンプレートを作成します。<br/> 文字数の詳細ガイドは[お知らせトークテンプレート注意事項](https://docs.nhncloud.com/ko/Notification/KakaoTalk%20Bizmessage/ko/alimtalk-overview/#_3)で確認してください。
    * 変数は #{変数} の形式で記述します。（例: #{홍길동}様の荷物は本日（#{09:50}）にお届け予定です。）
    * ボタン登録時、ボタン名には変数を入力できませんが、ボタンURLには変数を入力できます。（例: http://kakao.com/#{変数}）
    * ボタンURL登録時、url_mobile および url_pc リンクには「http://」または「https://」が含まれている必要があり、scheme_ios および scheme_android リンクはスキーム形式に合わせて登録する必要があります。そうでない場合、テンプレートの登録はできません。
* セキュリティテンプレートの有無
    * テンプレートにセキュリティを設定した場合、モバイル以外のデバイスではメッセージの内容が表示されません（「モバイルでご確認ください」の文言が表示されます）。
    * 通常のメッセージの場合、審査時に設定値が変更される可能性があります。OTP、認証番号、パスワード、信用情報/等級変更案内テンプレートは必ずセキュリティにチェックを入れてください。

<a id="alimtalk-template-button"></a>

#### お知らせトークテンプレートボタン
* テンプレートあたり最大5つのボタンを登録できます。
* クイック接続
    * 配送照会およびプラグインタイプは使用できません。その他のタイプはボタンと同様に使用できます。
    * テンプレートあたり最大10個まで使用でき、クイック接続使用時はボタンの数は2個に制限されます。

| ボタン種類 | 説明 |
| --- | --- |
| 配送照会 | - 配送業者の配送照会ページに移動します。<br/> - 配送照会ボタンをサポートする配送業者および配送業者別の伝票番号パターンを確認します。 [[お知らせトーク配送照会伝票番号パターン案内]](https://www.nhncloud.com/kr/support/notice/detail/1455)|
| Webリンク | - モバイルまたはPC Webページに移動します。<br/> - URLリンクを変数として設定できます。 |
| アプリリンク | - カスタムスキームでアプリを起動します。<br/> - AndroidとiOSで起動するカスタムスキームをそれぞれ設定する必要があります。 |
| ボットキーワード | - ボタン名が相談員に転送されます。<br/> - 相談トークをサポートしないチャンネルがこのボタンを追加すると、お知らせトークの送信はできません。 |
| メッセージ転送 | - ボタン名、メッセージ本文が相談員に転送されます。<br/> - 相談トークをサポートしないチャンネルがこのボタンを追加すると、お知らせトークの送信はできません。 |
| 相談トーク切替 | - 相談トークに接続されます。<br/> - 相談トークをサポートしないチャンネルがこのボタンを追加すると、お知らせトークの送信はできません。 |
| ボット切替 | - チャットボットが呼び出されます。<br/> - 相談トークをサポートしないチャンネルがこのボタンを追加すると、お知らせトークの送信はできません。 |
| チャンネル追加 | - お知らせトークを送信したチャンネルを追加します。表示位置は最初のボタンとしてのみ使用できます。<br/> - すでにチャンネルが追加されている場合、受信者には表示されません。 |
| イメージセキュリティ転送プラグイン | - チャット画面内で機密情報が含まれたイメージを暗号化して送信します。<br/> - ビズプラグインの作成が必要です。 [[ビズプラグインガイド]](https://business.kakao.com/info/talkbizplugin/) |
| 個人情報利用プラグイン | - チャット画面内で会員登録なしにサービス提供に必要な個人情報収集の同意を取得します。<br/> - ビズプラグインの作成が必要です。 [[ビズプラグインガイド]](https://business.kakao.com/info/talkbizplugin/) |
| ワンクリック決済プラグイン | - チャット画面内で画面遷移なしにユーザーが商品を決済できます。<br/> - 決済プラグインはプラットフォームでの直接登録をサポートしていないため、[Kakaoカスタマーセンター](https://cs.kakao.com/helps?service=127&category=572&locale=ko)にお問い合わせください。 | 
| ビジネスフォーム | - ビジネスフォームを作成して現在のチャンネルに接続した場合、ボタンクリック時に設定したビジネスフォームが呼び出されます。<br/> - ビジネスフォームの作成が必要です。 [[ビジネスフォームガイド]](https://business.kakao.com/info/talkbizform/) |

<a id="template-inspection"></a>

#### テンプレート審査
お知らせトークテンプレートの審査はKakaoが直接実施し、審査リクエスト後、営業日基準で2日以内に順次処理されます。

* テンプレートお問い合わせ登録
    * 審査リクエスト前にKakao審査担当者に伝えたい意見がある場合、お問い合わせ登録欄に内容を入力します。リクエスト/承認状態のテンプレートはお問い合わせできません（**[審査中/却下]** 状態のテンプレートのみお問い合わせ登録できます）。
    * 登録したお問い合わせは審査結果に追加され、Kakao審査担当者が確認します。
    * 審査結果にテンプレートの用途に関するお問い合わせ、却下理由の内容が追加されます。
    * テンプレートが却下された場合、**[お問い合わせ登録]** および **[修正]** をクリックして再審査を申請できます。

<a id="template-status"></a>

#### テンプレートステータス
* テンプレート登録時、**[リクエスト]** > **[審査中]** > **[承認/却下]** の順でステータスが更新されます。
* テンプレート登録後、1年間同一のステータスが維持されるか、追加送信がない場合、**[休眠]** 状態に移行します。関連ガイドは[お知らせトークテンプレート注意事項](https://docs.nhncloud.com/ko/Notification/KakaoTalk%20Bizmessage/ko/alimtalk-overview/#_3)で確認してください。

<a id="modify-templates"></a>

#### テンプレート修正
* **[承認/却下]** 状態のテンプレートのみ修正できます。
* 承認済みテンプレートを修正して審査が完了すると、既存のテンプレート内容が修正後の内容に置き換えられます。
* 発信プロフィール/グループおよびテンプレートコードは修正できません。
* 修正したテンプレートは **[審査中]** ステータスから再度審査が進行されます。

<a id="delete-templates"></a>

#### テンプレート削除
* リクエスト/却下状態のテンプレートのみ削除できます。
* 却下されたテンプレートは **[削除]** 後に再登録できます。
* 削除されたテンプレートコードは再利用できます。

<a id="brand-message-template"></a>

#### ブランドメッセージテンプレート
ブランドメッセージテンプレートはお知らせトークテンプレートとは異なり、審査プロセスがなく、作成、修正、削除が自由にできます。

* 発信プロフィールを選択してテンプレートを登録します。
* テンプレートコードはユーザーが直接登録する方式ではなく、Kakaoがランダムな識別子を付与します。
* メッセージタイプを選択して内容を作成します。
    * サポートするメッセージタイプ: テキスト、イメージ、ワイドイメージ、ワイドアイテムリスト、カルーセルフィード、プレミアム動画、コマース、カルーセルコマース
* ボタンを登録できます。
    * サポートするボタンタイプ: Webリンク、アプリリンク、ボットキーワード、メッセージ転送、相談トーク切替、ボット切替、ビジネスフォーム、チャンネル追加
* クーポンを登録できます。
* イメージを添付するには、先にイメージを登録する必要があります。

<a id="shared-alim-talk-template"></a>

#### 共通お知らせトークテンプレート
共通お知らせトークテンプレートは、Kakaoが直接制作して審査し、公開したテンプレートです。すべての事業者が共通して使用でき、特定の発信プロフィールに帰属しません。Kakaoの審査がすでに完了した状態で提供されるため、別途の審査リクエストなしにすぐに送信に使用できます。

* 自動登録
    * 発信プロフィールを登録すると、共通お知らせトークテンプレートが自動的に同期され、コンソールに表示されます。その後、Kakaoに新しい共通テンプレートが公開されると、定期的に自動同期されます。
    * 共通お知らせトークテンプレートは **[Kakao]** カテゴリの下に自動的に分類されます。このカテゴリはシステムが作成・管理するため、ユーザーが直接修正や削除はできません。
* 使用制限
    * 共通お知らせトークテンプレートはKakaoが管理するため、コンソールでの修正や削除はできません。
    * 共通お知らせトークテンプレートを一般カテゴリに移動したり、一般テンプレートを **[Kakao]** カテゴリに移動することはできません。
* 送信
    * 共通お知らせトークテンプレートは特定の発信プロフィールに帰属しないため、送信時に使用する発信プロフィールを直接選択する必要があります。
    * 有効状態の発信プロフィールが1つ以上登録されている必要があります。
    * 審査が完了した状態のため、審査待ちなしにすぐに送信できます。
