<h1>テンプレート</h1>

**Notification > Notification Hub > コンソール使用ガイド > テンプレート**


<span id="template"></span>

## テンプレート

よく使用するメッセージや一定の形式が必要なメッセージをテンプレートとして保存しておき、送信時に保存したテンプレートを設定してメッセージを送信できます。たとえば、カスタマーサポート、お知らせ、通知またはマーケティングメッセージなど、よく使用するメッセージの形式をテンプレートとして作成しておくと、毎回同じ内容を作成することなく、一部の情報だけ修正して送信できます。

<a id="category"></a>

### カテゴリ
* まずルートカテゴリを選択し、**[+ カテゴリ追加]** をクリックしてカテゴリを作成します。
* カテゴリは選択されたカテゴリの配下に作成されます。

<a id="template"></a>

### テンプレート
1. テンプレートが属するカテゴリを選択し、**[+ テンプレート登録]** をクリックします。テンプレート作成ページに移動し、選択されたメッセージチャンネルの追加設定が表示されます。
2. タイトルと内容、および各メッセージチャンネルで必要な設定を完了し、**[登録]** をクリックします。

<a id="alimtalk-template"></a>

#### お知らせトークテンプレート

お知らせトークテンプレートは、登録リクエスト後にカカオの審査承認を受けてから使用できます。

* 登録可能なメッセージタイプには、チャンネル追加型、基本型、付加情報型、複合型があります。
* 登録可能な強調タイプには、強調表記型、イメージ型、アイテムリスト型があります。
* 希望するタイプを選択してテンプレートを作成してください。

* カカオお知らせトークガイド
    * [[お知らせトーク制作ガイド]](https://kakaobusiness.gitbook.io/main/ad/bizmessage/notice-friend/content-guide)、[[お知らせトーク審査ガイド]](https://kakaobusiness.gitbook.io/main/ad/bizmessage/notice-friend/audit)、[[お知らせトークホワイトリスト]](https://kakaobusiness.gitbook.io/main/ad/bizmessage/notice-friend/audit/white-list)、[[お知らせトークブラックリスト]](https://kakaobusiness.gitbook.io/main/ad/bizmessage/notice-friend/audit/black-list)
* 発信プロフィール/グループ
    * テンプレートを登録する発信プロフィールまたは発信プロフィールグループを選択します。グループに登録する場合、グループに含まれるすべての発信プロフィールがそのテンプレートを使用できます。
    * 発信プロフィール/グループに同一のテンプレートコードが存在する場合、発信プロフィールに登録されたテンプレートが優先して送信されます。
    * 発信プロフィールグループの場合、メッセージタイプのうち「チャンネル追加型」「複合型」ではテンプレートを登録できません。
* テンプレートコード/テンプレート名
    * 1つの発信プロフィール/グループに同一のテンプレートコードとテンプレート名を重複して登録することはできません。

* テンプレート内容
    * お知らせトークは日本語・英語を問わず、変数およびURL、スペース、ボタン名をすべて含めて1,000文字まで作成できます。変数を入力して登録する場合は、置換される内容も考慮してテンプレートを作成してください。<br/> 文字数の詳細ガイドは[お知らせトークテンプレートの注意事項](https://docs.nhncloud.com/ja/Notification/KakaoTalk%20Bizmessage/ko/alimtalk-overview/#_3)で確認してください。
    * 変数を `#{変数}` の形式で記述します。（例: `#{홍길동}`님の宅配便が本日（`#{09:50}`）にお届けされる予定です。）
    * ボタン登録時、ボタン名への変数入力はできませんが、ボタンURLへの変数入力は可能です。（例: `http://kakao.com/#{変数}`）
    * ボタンURLを登録する際、url_mobile・url_pc リンクには `http://` または `https://` が含まれている必要があります。scheme_ios・scheme_android リンクはスキーム形式に合わせて登録してください。これに従わない場合、テンプレートの登録ができません。
* セキュリティテンプレートの有無
    * テンプレートをセキュリティ設定にした場合、モバイル以外のデバイスではメッセージ内容が表示されません。（「モバイルでご確認ください」の文言が表示されます。）
    * 通常メッセージの場合、審査時に設定値が変更される場合があります。OTP・認証番号・パスワード・信用情報/等級変更通知テンプレートは必ずセキュリティを設定してください。

#### お知らせトークテンプレートボタン
* テンプレートごとに最大5つのボタンを登録できます。
* バイダイレクト（바로연결）
    * 配送照会およびプラグインタイプは使用できません。それ以外のタイプはボタンと同様に使用できます。
    * テンプレートごとに最大10個まで使用でき、バイダイレクトを使用する場合、ボタンの数は2個に制限されます。

| ボタン種類 | 説明 |
| --- | --- |
| 配送照会 | - 宅配業者の配送照会ページに移動します。<br/> - 配送照会ボタンをサポートする宅配業者および宅配業者別の送り状番号パターンを確認します。 [[お知らせトーク配送照会送り状番号パターン案内]](https://www.nhncloud.com/kr/support/notice/detail/1455)|
| Webリンク | - モバイルまたはPC Webページに移動します。<br/> - URLリンクを変数として設定できます。 |
| アプリリンク | - カスタムスキームでアプリを起動します。<br/> - AndroidとiOSで起動するカスタムスキームをそれぞれ設定する必要があります。 |
| ボットキーワード | - ボタン名がオペレーターに転送されます。<br/> - 相談トークをサポートしないチャンネルがこのボタンを追加すると、お知らせトークの送信ができません。 |
| メッセージ転送 | - ボタン名とメッセージ本文がオペレーターに転送されます。<br/> - 相談トークをサポートしないチャンネルがこのボタンを追加すると、お知らせトークの送信ができません。 |
| 相談トーク切替 | - 相談トークに接続されます。<br/> - 相談トークをサポートしないチャンネルがこのボタンを追加すると、お知らせトークの送信ができません。 |
| ボット切替 | - チャットボットが呼び出されます。<br/> - 相談トークをサポートしないチャンネルがこのボタンを追加すると、お知らせトークの送信ができません。 |
| チャンネル追加 | - お知らせトークを送信したチャンネルを追加します。表示位置は1番目のボタンとしてのみ使用可能です。<br/> - すでにチャンネルが追加されている場合、受信者には表示されません。 |
| イメージセキュリティ送信プラグイン | - チャット画面内で機密情報を含む画像を暗号化して送信します。<br/> - BizPluginの作成が必要です。 [[BizPluginガイド]](https://business.kakao.com/info/talkbizplugin/) |
| 個人情報利用プラグイン | - チャット画面内で会員登録なしにサービス提供に必要な個人情報収集の同意を取得します。<br/> - BizPluginの作成が必要です。 [[BizPluginガイド]](https://business.kakao.com/info/talkbizplugin/) |
| ワンクリック決済プラグイン | - チャット画面内で画面遷移なしにユーザーが商品を決済できます。<br/> - 決済プラグインはプラットフォームからの直接登録をサポートしていないため、[カカオカスタマーセンター](https://cs.kakao.com/helps?service=127&category=572&locale=ko)にお問い合わせください。 |

<a id="template-inspection"></a>

#### テンプレート審査
お知らせトークテンプレートの審査はカカオが直接行い、審査リクエスト後、営業日基準2日以内に順次処理されます。

* テンプレート問い合わせ登録
    * 審査リクエスト前にカカオの審査担当者に伝えたい意見がある場合、問い合わせ登録欄に内容を入力します。リクエスト/承認状態のテンプレートは問い合わせできません。（**審査中/返却**状態のテンプレートのみ問い合わせを登録できます。）
    * 登録した問い合わせは審査結果に追加され、カカオの審査担当者が確認します。
    * 審査結果にテンプレートの用途に関する問い合わせや返却理由の内容が追加されます。
    * テンプレートが返却された場合、**[問い合わせ登録]** および **[修正]** をクリックして再審査を依頼できます。

<a id="template-status"></a>

#### テンプレートステータス
* テンプレート登録時、**リクエスト > 審査中 > 承認/返却** の順にステータスが更新されます。
* テンプレート登録後、1年間同じステータスが維持されるか、追加の送信がない場合、**休眠**ステータスに移行します。関連ガイドは[お知らせトークテンプレートの注意事項](https://docs.nhncloud.com/ja/Notification/KakaoTalk%20Bizmessage/ko/alimtalk-overview/#_3)で確認してください。

<a id="modify-templates"></a>

#### テンプレートの修正
* **承認/返却**状態のテンプレートのみ修正できます。
* 承認済みテンプレートを修正して審査が完了すると、既存のテンプレート内容が修正した内容に置き換えられます。
* 発信プロフィール/グループおよびテンプレートコードは修正できません。
* 修正したテンプレートは**審査中**状態から再度審査が進行されます。

<a id="delete-templates"></a>

#### テンプレートの削除
* リクエスト/返却状態のテンプレートのみ削除できます。
* 返却されたテンプレートは**削除**後に再登録できます。
* 削除されたテンプレートコードは再利用できます。

#### ブランドメッセージテンプレート
ブランドメッセージテンプレートはお知らせトークテンプレートと異なり審査プロセスがなく、作成・修正・削除を自由に行えます。

* 発信プロフィールを選択してテンプレートを登録します。
* テンプレートコードはユーザーが直接登録する方式ではなく、カカオがランダムな識別子を付与します。
* メッセージタイプを選択して内容を作成します。
    * サポートするメッセージタイプ: テキスト、イメージ、ワイドイメージ、ワイドアイテムリスト、カルーセルフィード、プレミアム動画、コマース、カルーセルコマース
* ボタンを登録できます。
    * サポートするボタンタイプ: Webリンク、アプリリンク、ボットキーワード、メッセージ転送、相談トーク切替、ボット切替、ビジネスフォーム、チャンネル追加
* クーポンを登録できます。
* イメージを添付するには、先にイメージを登録する必要があります。

#### 共用お知らせトークテンプレート
共用お知らせトークテンプレートは、カカオが直接制作・審査して公開したテンプレートです。すべての事業者が共通して使用でき、特定の発信プロフィールに帰属しません。カカオの審査が完了した状態で提供されるため、別途の審査リクエストなしにすぐに送信に使用できます。

* 自動登録
    * 発信プロフィールを登録すると、共用お知らせトークテンプレートが自動的に同期されてコンソールに表示されます。その後カカオに新しい共用テンプレートが公開されると、定期的に自動同期されます。
    * 共用お知らせトークテンプレートは**カカオ**カテゴリ配下に自動的に分類されます。このカテゴリはシステムが作成・管理するため、ユーザーが直接修正または削除することはできません。
* 使用制約
    * 共用お知らせトークテンプレートはカカオが管理するため、コンソールで修正または削除することはできません。
    * 共用お知らせトークテンプレートを一般カテゴリに移動したり、一般テンプレートを**カカオ**カテゴリに移動したりすることはできません。
* 送信
    * 共用お知らせトークテンプレートは特定の発信プロフィールに帰属しないため、送信時に使用する発信プロフィールを直接選択する必要があります。
    * アクティブ状態の発信プロフィールが1つ以上登録されている必要があります。
    * 審査が完了した状態のため、審査待ちなしにすぐに送信できます。
