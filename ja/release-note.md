<h1>Notification Hub リリースノート</h1>

**Notification > Notification Hub > リリースノート**

## 2026. 06. 23.
### 機能追加
* [コンソール] お知らせトーク共用テンプレート機能を追加しました。
    * 注文、決済、配送など業種を問わず汎用的に使用できるメッセージテンプレートを提供します。別途の審査プロセスなしで使用できます。
* [コンソール、API] ブランドメッセージチャンネルをリリースしました。
    * カカオブランドメッセージの送信をサポートします。
    * 送信対象：顧客企業の会員向け（M、N、Oグループ）、チャンネル友だち向け（既存 I グループターゲティング送信）
    * 既存の KakaoTalk Bizmessage のブランドメッセージとの主な相違点：
        * O グループターゲティングの追加：顧客企業の広告性受信同意会員のうち、チャンネル友だちへの送信
        * 顧客企業の会員向けメッセージは、カカオトーク 25.4.0 以上のユーザーのみ受信可能

## 2026. 05. 27.
<a id="added-features"></a>

### 機能追加
* [API] カカオビズセンター統計照会 API を追加しました。
    * カカオビズセンターが提供するお知らせトーク、ブランドメッセージの送信統計およびテンプレート統計を照会できる API が追加されました。
    * 発信キー基準で日別（DAILY）または月別（MONTHLY）の統計データを照会できます。
    * 詳細については、[API v1.0 使用ガイド > カカオ統計](./api-guide-v1x0/kakao-statistics)を参照してください。

<a id="march-24-2026"></a>

## 2026. 03. 24.
<a id="added-features-2"></a>

### 機能追加
* [API、コンソール] 統合 RCS メッセージをサポートしました。
    * Android、iOS 端末のどちらでも受信可能な統合 RCS メッセージの送信をサポートします。
    * 送信可能な統合 RCS メッセージのタイプについては、[利用ポリシーおよび事前設定案内 > RCS](./service-policy-and-precondition/rcs)を参照してください。
* [コンソール] カカオビズセンター統計を提供しました。
    * カカオビズセンターが提供するお知らせトーク、ブランドメッセージの統計データを照会できる機能を提供します。
* [API、コンソール] カカオビズセンターグループタグ管理機能を提供しました。
    * カカオビズセンターが提供するグループタグを管理できる機能を提供します。
* [コンソール] メッセージ送信履歴のバックアップ結果通知を追加しました。
    * メッセージ保管期間を過ぎたメッセージ送信履歴のバックアップ設定時に、結果通知を受け取ることができます。
    * **プロジェクトダッシュボード > 通知管理**で設定できます。

## 2025. 12. 04.
<a id="feature-improvements"></a>

### 機能改善
* [API] イメージレイアウト一覧照会 API に `exact` リクエストパラメーターが追加されました。
    * 従来は `name` パラメーターで名前を指定した場合、部分一致（LIKE）検索が適用されていました。
    * `exact` パラメーターを `true` に設定すると、名前が完全に一致するイメージレイアウトのみ照会されます。

<a id="07-29"></a>

## 2025. 07. 29.
<a id="new-features"></a>

### 機能追加
* [API/コンソール] イメージレイアウト機能が追加されました。
    * イメージレイアウトは、パーソナライズされた MMS 添付イメージを生成するための機能です。
    * イメージレイアウトは MMS テンプレート作成時に選択でき、MMS テンプレートに連携したイメージレイアウトを通じてパーソナライズされたイメージを生成できます。
    * 詳細については、[コンソール使用ガイド > 送信](./console-guide/image-layout)、[API v1.0 使用ガイド > メッセージ > イメージレイアウト](./api-guide-v1x0/image-layout)を参照してください。
* [API/コンソール] MMS テンプレートにイメージレイアウトを連携できます。
    * MMS テンプレート作成時に添付ファイルセクションでイメージレイアウトを選択できます。
    * 詳細については、[コンソール使用ガイド > テンプレート](./console-guide/template/#templateV1x0001CreateSmsTemplate) [API v1.0 使用ガイド > メッセージ > MMS テンプレート](./api-guide-v1x0/template/#templateV1x0001CreateSmsTemplate)を参照してください。
* [コンソール] 国際 SMS 送信時、送信詳細照会でエンコーディングおよび実送信件数を確認できます。
* [コンソール] 「添付ファイル管理」メニューの位置が変更されました。
    * 「詳細設定」メニュー配下にあった添付ファイル管理メニューが上部メニューに移動されました。

## 2025. 02. 11.

<a id="new-features-7"></a>

### 機能追加
* [コンソール/API] RCS BizCenter LMS テンプレート送信をサポートしました。
    * RCS BizCenter LMS テンプレートタイプも送信できます。
* [API] Instant Flow Message API を追加しました。
    * 事前にフローやテンプレートを登録しなくても、リクエスト時点でメッセージを即時作成・送信できる API が追加されました。
    * 詳細については、[API v1.0 使用ガイド > メッセージ > インスタントフローメッセージ送信](./api-guide-v1x0/message/#_6)を参照してください。
* [コンソール/API] 送信受信者の重複チェック機能を追加しました。
    * 受信者リストに重複した連絡先が存在する場合、送信前に確認して重複送信を防ぐことができます。
* [コンソール] フローテンプレートのプレビュー機能を追加しました。
    * フロー管理メニューで、フローに含まれる複数チャンネルのテンプレートをプレビューできる機能が追加されました。
* [コンソール] お知らせトーク バロ連結プレビューを追加しました。
    * お知らせトークチャンネルのテンプレートプレビューで「バロ連結」項目を確認できるよう修正されました。
* [API] 送信 API のユーザーカスタムフィールドを追加しました。
    * 送信 API リクエスト時にユーザーカスタムフィールドを含めてリクエストできるよう追加されました。
    * 詳細については、[API v1.0 使用ガイド > メッセージ](./api-guide-v1x0/message)を参照してください。

<a id="enhancements-4"></a>

### 機能改善
* [コンソール/API] RCS テンプレート機能を改善しました。
    * RCS BizCenter に登録したテンプレートを再登録しなくても連携されるよう改善されました。
        * ブランド連携時にテンプレートへ自動的に連携されます。
        * RCS BizCenter テンプレートの手動での登録/修正/削除はできません。
        * RCS BizCenter テンプレートはチャットボット、受信拒否番号が空欄で登録され、送信時のチャットボットは最後に登録したチャットボットで送信されます。
